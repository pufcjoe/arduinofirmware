# Fnatic Bolt USB Passthrough

USB HID passthrough firmware for the **Fnatic Bolt** using an **Arduino Leonardo R3** and **USB Host Shield 2.0**.

The Leonardo reads raw HID reports from the Bolt via the Host Shield and re-transmits them to the PC through its native USB — matching the real mouse's USB identity and HID descriptor 1:1.

## Mouse Info (dumped from real hardware)

| Field | Value |
|-------|-------|
| VID | `0x2F0E` |
| PID | `0x0203` |
| bcdDevice | `0x0100` |
| Manufacturer | `Fnatic Gear` |
| Product | `FNATIC BOLT Mouse` |
| Serial | `000000000000` |
| bcdUSB | `0x0200` |
| bcdHID | `0x0111` |

### Mouse Interface (Interface 0)

| Field | Value |
|-------|-------|
| bInterfaceClass | 3 (HID) |
| bInterfaceSubClass | 1 (Boot Interface) |
| bInterfaceProtocol | 2 (Mouse) |
| bEndpointAddress | `0x81` (IN 1) |
| bmAttributes | `0x03` (Interrupt) |
| wMaxPacketSize | 64 |
| bInterval | 1 ms (1000 Hz) |
| bmConfigAttributes | `0xE0` (self-powered, remote wakeup) |
| MaxPower | 100 mA |

### HID Report (7 bytes, no report ID)

| Bits | Field | Range |
|------|-------|-------|
| 0–4 | Buttons (5) | 0/1 absolute |
| 5–7 | Padding | — |
| 8–23 | X (16-bit LE) | -32767..32767 relative |
| 24–39 | Y (16-bit LE) | -32767..32767 relative |
| 40–47 | Wheel (8-bit) | -127..127 relative |
| 48–55 | AC Pan (8-bit) | -127..127 relative |

### Real Device Composite Structure

The real Bolt is a 3-interface USB composite device:

| Interface | Class | SubClass | Protocol | Endpoints | Description |
|-----------|-------|----------|----------|-----------|-------------|
| 0 | HID | Boot | Mouse | IN 0x81 | Mouse reports (73-byte descriptor) |
| 1 | HID | Boot | None | IN 0x82 + OUT 0x02 | Vendor config (34-byte descriptor) |
| 2 | HID | Boot | Keyboard | IN 0x83 | Keyboard + Consumer + Vendor (124-byte descriptor) |

## Requirements

### Hardware
- Arduino Leonardo R3
- USB Host Shield 2.0 (stacks directly onto the Leonardo)
- USB cable (Leonardo to PC)
- Fnatic Bolt (plugs into Host Shield USB-A port)

### Software
- [Arduino IDE](https://www.arduino.cc/en/software)
- **USB Host Shield Library 2.0** (install via Library Manager)

## Setup

1. **Apply core patches** (one-time): see the Dell mouse README for the list of patches needed. They are shared across all board definitions.
2. Copy `boards.local.txt` from the repo root to your Arduino AVR core directory:
   ```
   %LOCALAPPDATA%\Arduino15\packages\arduino\hardware\avr\<version>\
   ```
3. Restart the Arduino IDE.
4. Select **Board: Arduino Leonardo (Fnatic Bolt)**.
5. Flash the sketch.
6. Plug the Fnatic Bolt into the USB Host Shield's USB-A port.

> **Note:** CDC serial is disabled so the PC sees a pure HID mouse. To re-flash, **double-tap the Leonardo's reset button**.

## What matches 1:1

- VID, PID, bcdDevice, bcdUSB
- Manufacturer and product strings
- HID report descriptor (73 bytes — 5 buttons, 16-bit X/Y, 8-bit wheel, 8-bit AC pan)
- Interface class/subclass/protocol (HID Boot Mouse)
- Endpoint packet size (64) and polling interval (1ms / 1000 Hz)
- Configuration attributes (self-powered, remote wakeup) and power (100 mA)
- bcdHID version (0x0111)
- No CDC interface (pure HID)
- Raw 7-byte reports forwarded without modification

## What differs

- **Composite structure**: real Bolt has 3 interfaces; this firmware exposes only the mouse interface (IF0). Interfaces 1 (vendor config) and 2 (keyboard/consumer) are not replicated.
- **Serial number**: auto-generated by the Arduino HID library instead of the real "000000000000".

## Debugging

Set `DEBUG_RAW` to `1` at the top of the sketch, then use a board definition with CDC enabled (or create a debug variant). Open Serial Monitor at 115200 baud.
